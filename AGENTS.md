# Repository agent guide

## Repository workflow and completion

The README plus `context/` and `docs/` curate browser WebMCP resources. `contributing.md` excludes ordinary server-side MCP, requests one entry per PR, and specifies a linked name plus concise sentence ending in a period. Preserve restrictions on promotional wording/star counts and justify new categories.

No runtime or build/test suite is defined. Check authoritative source, category, changed links, duplicates, and Markdown. Do not install extensions or execute demos as link checks. Source reachability differs from working implementation/browser-support evidence.

Continue the authorized change through relevant validation and repair of failures it causes; preserve unrelated work. Report checks actually run, commands only inspected, and exact missing prerequisites. Ask only when a material decision, missing authorization, or required input blocks progress; continue independent reversible work. Existing mandatory contribution and validation gates still apply.
